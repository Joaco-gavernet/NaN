# Contest templates

- [C++ solution](cpp/solution.cpp): the full starting template and common aliases.
- [Fast IO](cpp/fast_io.cpp): the compact setup selected for World Finals.
- [Timing snippet](cpp/timing.cpp): measuring local execution time.
- [Compiler notes](cpp/compiler_notes.sh): editor commands and shell examples;
  read and adapt these notes rather than executing the entire file.

Algorithms are snippets and may require aliases, macros, includes, or constants
from a template. They are not a single library that can be linked together.
