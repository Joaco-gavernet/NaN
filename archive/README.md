# Historical material

These files are historical references, excluded from the active notebook build
and CI checks. Edit the [current library](../algorithms/README.md) for ongoing work.

- [Previous World Finals](wf_previous/): earlier event snapshot, with its source
  and original generation scripts.
- [PDA 2026](pda_2026/): earlier event snapshot, with its source and original scripts.
- [WF26 before reorganization](wf_2026_before_reorganization.pdf): the 24-page PDF
  before the library and manifest split.
- [Original collection PDF](original/notebook.pdf): historical printed notebook.
- `wf_2026_support/`: unused presentation material and a source backup.
- `original/`: original supporting material and the retired six-base
  factorization implementation. That implementation has the known issue #9 bug;
  use the maintained library's Miller–Rabin/Pollard–Rho implementation instead.

Historical scripts use their original relative layout and may require old local
TeX tooling. They are preserved for reference, not supported build entry points.
Git history also preserves all former paths and versions.
